# PDF 강의자료 한글 요약

사용자가 PDF 경로(와 선택적으로 페이지 범위)를 주면 아래 절차를 따른다.

## 1단계: 텍스트 추출

페이지 범위가 없으면 전체를, 있으면 `-f`/`-l` 옵션으로 범위를 지정해 추출한다.

```bash
# 전체
pdftotext "경로/파일.pdf" -

# 페이지 범위 (예: 1~24)
pdftotext -f 1 -l 24 "경로/파일.pdf" -
```

출력이 너무 길면 임시 파일로 저장 후 Read로 읽는다.

```bash
pdftotext "경로/파일.pdf" /tmp/lecture.txt
```

poppler가 없으면 설치 안내: `brew install poppler`

## 2단계: 한글 요약 작성

추출된 텍스트를 아래 규칙으로 한글 요약한다.

### 형식 규칙
- 챕터 제목: `# Ch{N}. 제목 요약`
- 개념/섹션 구분: `##`, `###` 헤더
- 개념 비교·분류·속성 나열 → **반드시 마크다운 표** 사용
- 코드, 명령어, 수식 → 코드블록
- 흐름·단계 → 화살표(`→`) 또는 번호 목록

### 내용 규칙
- 슬라이드 번호, 저자 정보(`Silberschatz` 등)는 제외
- 영어 원문이어도 요약은 **한글**로 작성
- 기술 용어는 **한글(영어)** 병기: 예) **문맥 교환(Context Switch)**
- 약어 첫 등장 시 풀어쓰기: 예) PCB(Process Control Block)
- 교수 필기(한글 메모)가 있으면 요약에 반영
- 시험 범위 표시 등 특이사항은 인용문(`>`)으로 별도 언급

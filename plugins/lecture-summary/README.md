# lecture-summary — PDF 강의자료 한글 요약

PDF 강의자료를 받아 **한글 요약 노트**로 정리합니다. 영어 슬라이드여도 요약은 한글로 쓰고, 기술 용어는 한글과 영어를 같이 적습니다. 개념 비교는 표로, 코드와 수식은 코드블록으로 정리해서 시험 공부에 바로 쓸 수 있는 형태를 목표로 합니다.

원문에 없는 설명을 덧붙이는 도구가 아닙니다. 슬라이드에서 뽑은 텍스트를 구조화해서 요약합니다.

## 설치

```
/plugin marketplace add donghyeun02/claude-kit
/plugin install lecture-summary@claude-kit
```

텍스트 추출에 `pdftotext`를 씁니다. 없으면 먼저 설치하세요.

```bash
brew install poppler
```

## 사용법

PDF 경로를 주고 요약해 달라고 하면 됩니다.

```
~/study/os/ch3-process.pdf 요약해줘
```

페이지 범위를 지정할 수 있습니다.

```
~/study/os/ch3-process.pdf 1~24페이지만 정리해줘
```

"요약", "정리", "summarize" 같은 표현에서 동작합니다.

## 동작 방식

```
1. 텍스트 추출 ── pdftotext. 범위가 있으면 -f/-l 옵션
    ↓           출력이 길면 임시 파일로 저장한 뒤 읽음
2. 한글 요약 ── 아래 형식·내용 규칙대로
```

```bash
pdftotext "파일.pdf" -                 # 전체
pdftotext -f 1 -l 24 "파일.pdf" -      # 1~24쪽
```

## 형식 규칙

| 대상 | 표현 |
|---|---|
| 챕터 제목 | `# Ch{N}. 제목 요약` |
| 개념·섹션 구분 | `##`, `###` 헤더 |
| 개념 비교·분류·속성 나열 | 마크다운 표 (반드시) |
| 코드·명령어·수식 | 코드블록 |
| 흐름·단계 | `→` 화살표 또는 번호 목록 |

## 내용 규칙

| 규칙 | 예 |
|---|---|
| 슬라이드 번호·저자 정보는 뺀다 | 교재 저자명 반복 표기 제거 |
| 영어 원문이어도 요약은 한글로 | — |
| 기술 용어는 한글(영어) 병기 | 문맥 교환(Context Switch) |
| 약어는 처음 나올 때 풀어 쓴다 | PCB(Process Control Block) |
| 교수 필기(한글 메모)가 있으면 반영 | — |
| 시험 범위 같은 특이사항은 인용문으로 따로 | `> 중간고사 범위` |

## 알려진 한계

- **스캔본 PDF는 안 됩니다.** `pdftotext`는 텍스트 레이어만 읽습니다. 이미지로만 된 PDF는 빈 결과가 나오고, 이 스킬에는 OCR 단계가 없습니다.
- 도표·그림 안의 글자는 텍스트 레이어에 없으면 빠집니다. 그림으로 설명하는 슬라이드는 요약이 얇아질 수 있습니다.
- 수식이 이미지로 들어간 슬라이드는 수식이 누락될 수 있습니다.
- 교수 필기는 PDF에 텍스트 주석으로 들어가 있을 때만 읽힙니다. 손글씨 스캔은 읽지 못합니다.

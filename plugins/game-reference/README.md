# game-reference — 게임 레퍼런스 찾기

만들려는 게임의 레퍼런스(벤치마크 게임)를 **감이 아니라 시장 데이터로** 찾습니다. 기준은 미국 매출 순위입니다. 미국은 인앱결제 규모와 자연 유입 유저 수가 모두 가장 큰 시장이라, 거기서 상위권이면 글로벌 성적으로 이어진다고 봅니다.

"재미있어 보이는 게임 추천"이 아닙니다. 매출 순위로 추리고, 리텐션으로 걸러서, 배울 점과 차별화 기회를 같이 내놓습니다.

## 설치

```
/plugin marketplace add donghyeun02/skill-kit
/plugin install game-reference@skill-kit
```

## 사용법

스킬 이름을 부르지 않아도 됩니다. 이런 식으로 말하면 붙습니다.

```
캔디크러쉬 같은 매치3 퍼즐 게임 만들려고 하는데 어떤 게임을 레퍼런스로 삼아야 할까?
나는 모바일 캐주얼 타겟이고 data.ai 접근은 없어.
```

```
Zhed랑 비슷한 미니멀 로직 퍼즐 게임을 만들고 싶어.
시장에서 잘 되고 있는 비슷한 게임들이 뭐가 있는지 레퍼런스 분석해줘.
```

```
합성 게임이나 아이들 게임 쪽으로 기획 중인데
글로벌 시장에서 지금 잘 되고 있는 게임이 뭔지 알고 싶어.
```

"레퍼런스 찾아줘", "벤치마크 게임 추천", "경쟁작 분석", "게임 기획 레퍼런스" 같은 표현에서 동작합니다.

세부 장르·핵심 메카닉·타겟 플레이어·플랫폼을 처음부터 같이 적으면 질문 없이 바로 분석으로 넘어갑니다. 빠진 게 있을 때만 되묻습니다.

## 동작 방식

```
1. 세부 장르 확정 ── 스토어 카테고리가 아니라 실제 장르로
    ↓
2. 미국 매출 순위 확인 ── data.ai가 있으면 Top 100, 없으면 공개 소스를 웹 검색
    ↓
3. 같은 세부 장르만 추리기 ── 스테디셀러 / 신규 진입으로 분류
    ↓
4. 리텐션으로 거르기 ── 장르 평균보다 D+1·D+7이 높은 게임이 핵심 레퍼런스
```

### 1. 세부 장르가 먼저인 이유

스토어 카테고리는 너무 넓습니다. "캐주얼" 안에 매치3와 아이들 게임이 같이 들어 있고, 둘은 레퍼런스로 삼을 대상이 완전히 다릅니다.

| 스토어 카테고리 | 실제 세부 장르 |
|---|---|
| 캐주얼 | 매치3, 로직퍼즐, 버블슈터, 러너, 아이들, 합성 |
| 전략 | 타워디펜스, 4X, 실시간전략, 기지건설 |
| RPG | 액션RPG, 턴제RPG, 로그라이크RPG |

### 2. 데이터 소스

data.ai 접근이 있으면 미국 iOS·Android 매출 Top 100에서 장르를 필터링하고, 최근 30일과 3개월 전을 비교해 순위가 안정적인지 봅니다.

접근이 없으면 학습된 지식에 기대지 않고 **반드시 검색해서** 현재 순위를 확인합니다.

| 소스 | 용도 |
|---|---|
| Sensor Tower 블로그 | 장르별 매출 상위 |
| AppMagic 리포트 | 장르 리포트 |
| PocketGamer · Deconstructor of Fun | 장르 시장 분석 |
| App Store · Google Play 차트 | 현재 카테고리 Top 100 직접 확인 |

### 3. 스테디셀러와 신규 진입

| 구분 | 기준 | 의미 |
|---|---|---|
| 스테디셀러 | 2년 이상 순위 유지 | 검증된 메카닉, 대신 진입장벽이 높음 |
| 신규 진입 | 최근 6개월 이내 | 시장이 지금 반응하는 흐름 |

게임마다 핵심 메카닉 1~2줄, 수익화 방식(광고형·인앱결제·하이브리드), 차별화 포인트를 요약합니다.

### 4. 리텐션 기준값 (모바일 캐주얼)

리텐션은 핵심 재미가 얼마나 강한지 보여주는 지표로 씁니다.

| 지표 | 보통 | 우수 | 탁월 |
|---|---|---|---|
| D+1 | ~40% | ~50% | 60%+ |
| D+7 | ~10% | ~15% | 20%+ |

## 출력 형식

결과는 항상 이 모양입니다.

```
## 추천 레퍼런스 게임

| 게임명 | 세부 장르 | 미국 매출 순위 | D+1 추정 | D+7 추정 | 핵심 메카닉 |
|--------|----------|--------------|---------|---------|-----------|

## 핵심 레퍼런스: [게임명]

### 배울 점
- 메카닉, UX, 수익화 구조

### 차별화 기회
- 이 게임이 못하거나 약한 점, 시장의 빈틈

## data.ai에서 직접 확인할 항목
- [ ] 미국 iOS 매출 Top 100 중 [세부 장르] 게임 목록
- [ ] [게임명] D+1, D+7 리텐션 vs 장르 평균
- [ ] 최근 6개월 신규 진입 [세부 장르] 게임
```

마지막 체크리스트는 스킬이 공개 소스로 대신한 부분을 사람이 원본 데이터로 확인하라는 뜻입니다.

## 원칙

- 레퍼런스는 베낄 대상이 아니라 **차별화의 기준선**입니다. 결과에서도 그렇게 안내합니다.
- 리텐션 공개 데이터가 없으면 유사 게임 평균과 업계 벤치마크로 추정하고, **추정치라고 표시**합니다.
- 웹 검색으로 가져온 수치는 출처 링크를 결과 맨 아래에 붙입니다. 출처 없는 순위는 믿기 어렵습니다.

## 알려진 한계

- data.ai 없이 돌리면 순위는 공개 리포트가 나온 시점 기준입니다. 리포트가 몇 달 지났으면 현재 순위와 다를 수 있습니다.
- 리텐션 기준값은 모바일 캐주얼 기준입니다. 코어·PC·콘솔 게임에 그대로 대면 안 맞습니다.
- 미국 매출 기준이라 특정 지역에서만 강한 게임(예: 국내 전용 IP)은 걸러질 수 있습니다.

## 평가 세트

`skills/find-game-reference/evals/evals.json`에 프롬프트 3건과 기대 출력이 있습니다(매치3 / 미니멀 로직 퍼즐 / 합성·아이들). 스킬을 고친 뒤 같은 프롬프트로 돌려 출력 형식과 분류가 유지되는지 확인하는 용도입니다.

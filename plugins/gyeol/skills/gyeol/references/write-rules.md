# Write Rules — 사전 작성용 (생성물)

<!-- 이 파일은 scripts/build_rules.py 가 voice-rules.md 에서 생성한다. 직접 고치지 말 것. -->

글을 **쓰기 전에** 주입하는 짧은 규칙. 여기 있는 것은 전부 문장을 쓰는 순간에 지킬 수
있는 것들이다. 밀도·분포·리듬처럼 완성된 글을 봐야 판정되는 규칙은 의도적으로 뺐다 —
문단이 끝나기 전에는 "이미 3번 썼다"를 알 수 없기 때문이다. 그쪽은 사후 패스가 맡는다.

---

## V. 목소리 — 이 저장소 고유 (레퍼런스 코퍼스에서 유도)

- **V-1** [S1] 구어 어미·1인칭·유보·자기비하를 의도적으로 남길 것
- **V-2** [S2] 문장 길이를 일부러 들쭉날쭉하게. 짧은 문장 하나를 아끼지 말 것
- **V-3** [S2] 해요체/합니다체 중 하나를 정하고 끝까지 유지
- **V-4** [S2] 마무리는 남은 숙제나 전제로. 전망으로 닫지 말 것
- **V-5** [S3] 수치·근거를 댔으면 그 한계를 한 줄 덧붙일 것

## T. 번역투 (출처: epoko77-ai/im-not-ai, MIT — 실측 보수화 반영)

- **T-1** [S1] '~에 있어(서)' 쓰지 말 것
- **T-2** [S1] '가지고 있다' 대신 '~이 ~하다'로
- **T-3** [S1] 이중 피동 금지
- **T-5** [S2] 행위자를 주어로 쓸 것
- **T-9** [S2] '-에서의/-으로의' 대신 절로 풀어쓸 것
- **T-11** [S2] 무생물·추상 주어에 '보여준다/제공한다' 붙이지 말 것

## P. 관용구·상투 (출처: im-not-ai D계열 + blader/humanizer, MIT)

- **P-1** [S1] '결론적으로/따라서/이를 통해'로 문단을 열지 말 것
- **P-2** [S2] 양비론으로 마무리하지 말 것. 조건을 구체적으로
- **P-3** [S2] '본질적으로/결국 중요한 건' 쓰지 말 것

## S. 구조·리듬

- **S-1** [S2] 항목 수를 억지로 3개로 맞추지 말 것
- **S-3** [S2] 'A에서 B까지' 는 실제 범위일 때만
- **S-4** [S2] 소제목을 첫 문장에서 되풀이하지 말 것

## F. 형식·장식

- **F-2** [S1] '**라벨:** 설명' 형태의 불릿을 쓰지 말 것
- **F-3** [S1] 헤딩·불릿에 이모지 붙이지 말 것
- **F-5** [S3] 소제목은 문장형으로

## 판정 유보 원칙

한 축만 걸리면 보류한다. 독립된 축 2개 이상이 동시에 걸릴 때만 처리한다.
깔끔한 문장·격식체·접속부사 1회·볼드의 존재·긴 문장은 그 자체로 증거가 아니다.
